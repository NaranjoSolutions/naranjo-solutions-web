## The project

Orthopedic Spine is a clinic platform that brings together a public-facing website, online booking, and an admin dashboard. The project connects the clinic’s online presence with the backend systems supporting these capabilities.

## What I built

The React site provides the public interface and online booking experience. An admin dashboard provides a separate interface for administration. A FastAPI backend and PostgreSQL database support the platform.

These pieces form a full-stack application: the website and dashboard provide the interfaces, the API connects them to backend functionality, and the database provides persistent storage.

## The engineering approach

The project spans frontend and backend development. React handles the user-facing application, FastAPI provides the backend API, and PostgreSQL stores the platform’s data.

This combination makes the clinic platform a concrete example of the work I offer through Naranjo Solutions: taking a business need across the interface, API, and data layers.

## What this demonstrates

A business website can be part of a wider software system. Here, the public website, booking experience, and admin dashboard are delivered together rather than treated as isolated pieces.

Client repositories and implementation details are private. This overview describes the delivered capabilities without exposing clinic or patient data.
