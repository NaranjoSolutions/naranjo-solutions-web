## El proyecto

Orthopedic Spine es una plataforma clínica que reúne un sitio web público, reservas en línea y un panel administrativo. El proyecto conecta la presencia en línea de la clínica con los sistemas de backend que sostienen estas funcionalidades.

## Lo que construí

El sitio en React ofrece la interfaz pública y la experiencia de reservas en línea. Un panel administrativo proporciona una interfaz independiente para la administración. Un backend en FastAPI y una base de datos PostgreSQL sostienen la plataforma.

Estas piezas forman una aplicación completa: el sitio web y el panel proporcionan las interfaces, la API las conecta con las funciones del backend y la base de datos ofrece almacenamiento persistente.

## El enfoque de ingeniería

El proyecto abarca el desarrollo de frontend y backend. React se encarga de la aplicación que utilizan los usuarios, FastAPI proporciona la API de backend y PostgreSQL almacena los datos de la plataforma.

Esta combinación convierte la plataforma clínica en un ejemplo concreto del trabajo que ofrezco a través de Naranjo Solutions: llevar una necesidad de negocio a las capas de interfaz, API y datos.

## Lo que demuestra

Un sitio web empresarial puede formar parte de un sistema de software más amplio. En este caso, el sitio público, la experiencia de reservas y el panel administrativo se entregan juntos como partes de una misma solución.

Los repositorios del cliente y los detalles de implementación son privados. Esta descripción presenta las funcionalidades entregadas sin exponer datos de la clínica ni de pacientes.
